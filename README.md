# cara dlí

Irish commercial-awareness learning website.

## Current structure

- `index.html` — website structure and page content
- `css/styles.css` — visual styling
- `js/app.js` — website interactions and sample content
- `assets/` — reserved for future images and other static assets

## GitHub upload

Upload the contents of this folder to the root of the `cara-dli` GitHub repository. Do not upload the ZIP file itself.
